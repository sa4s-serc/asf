# Project Website

This repository contains a Jekyll-based academic paper website template.

Based on the [Nerfies website](https://nerfies.github.io) template.

## Structure

- `index.html` - Main page (edit this with your paper content)
- `_config.yml` - Jekyll configuration
- `static/` - CSS, JS, and image assets
- `_layouts/` - Jekyll templates
- `_includes/` - Reusable components

## Test it locally

Install [Jekyll](https://jekyllrb.com/docs/installation/), and run:
```
jekyll serve
```
Then view the website at `http://127.0.0.1:4000`
